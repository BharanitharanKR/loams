# quickstart

Connects to a Loams engine and prints the instance info and the calling identity.

```sh
php examples/quickstart/main.php            # LOAMS_URL defaults to http://127.0.0.1:18080
```

The PHP SDK (preview) covers the instance, live, approval and device services.
It has no collection, search or SQL client yet, so there are no upsert/hybrid-search
examples here.
