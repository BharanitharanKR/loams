# The Live authorization matrix (LV1 plan Tasks 15 and 16)

Generated by `authz_matrix` (`crates/loams-live/tests/authz.rs`); `LOAMS_BLESS=1` rewrites it. Every call addresses the app `shop` (environment `shop/prod`). "app" is the credential's environment: unbound (none, the self-hosted default), same, or another's. `end_user` holds a token from the app's trusted issuer and `anonymous` no credential (the app takes no anonymous calls), both as the engine's layer leaves them to Live on `LiveService`; on `LiveAdminService` the engine refuses them first, so the admin rows show Live's own second check.
